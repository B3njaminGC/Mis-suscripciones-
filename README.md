# Mis suscripciones

App Android para controlar suscripciones y cobros recurrentes. Todo se guarda en el celular: sin cuentas, sin servidor, gratis.

## Compilar el APK

Cada push a `main` compila el APK en GitHub Actions. Descargalo desde la pestaña **Actions** → último run → **Artifacts** → `mis-suscripciones-apk`.

Para instalarlo en el celular, permití instalar apps de fuera de la tienda en ajustes de seguridad.

## Probar la lógica en tu PC

```
flutter pub get
flutter test
```
